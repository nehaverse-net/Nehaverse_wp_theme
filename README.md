# Nehaverse WordPress Theme

White and lavender game-site design with scroll motion. Version 2.0.0.

## インストール・更新

1. このリポジトリの中身を `wp-content/themes/nehaverse/` に配置します（既存テーマを上書き）。
2. 管理画面の「外観 > テーマ」で `Nehaverse` を有効化します（v1から更新した場合はそのままでOK）。
3. 「設定 > パーマリンク」を一度保存します（OGP画像のURLとお知らせのURLを反映するため）。

WordPress 6.3以上、PHP 8.0以上が必要です。

## ページ構成

次の固定ページを作成し、スラッグを合わせると専用テンプレートが自動適用されます。本文は空でかまいません（テンプレート側の内容が表示されます）。

| スラッグ | テンプレート | 内容 |
| --- | --- | --- |
| （フロントページ） | `front-page.php` | ヒーロー、最新記事、ワールド紹介、サービス紹介、稼働状況 |
| `minecraft` | `page-minecraft.php` | サーバー紹介、3つのワールド、接続情報 |
| `rules` | `page-rules.php` | ルール、参加方法、注意事項 |
| `products` | `page-products.php` | Bot・プラグイン紹介 |
| `contact` | `page-contact.php` | Discord窓口、運営応募フォーム |

「設定 > 表示設定」でホームページに固定ページを指定し、**投稿ページ**に「ニュース」などの空の固定ページを指定すると、ヘッダーの「ニュース」から記事一覧に移動できます。

その他の固定ページは `page.php`（見出しエリア＋本文）で表示されます。

## 記事（投稿）

普通に投稿した記事は `single.php` で、サイトと同じデザインで表示されます。

- 見出しエリア：パンくず、カテゴリー、投稿日・更新日、読了目安、タイトル（1文字ずつ表示）、抜粋、著者
- アイキャッチ画像：横幅いっぱいに、ワイプで表示（トリミングなし）
- 本文の見出し（H2/H3）から**目次を自動生成**し、PCでは左側に固定表示。読んでいる位置がハイライトされます
- シェアボタン（X・リンクコピー）、タグ、前後の記事、関連記事（同じカテゴリーから3件）、コメント
- ブロックエディタの段落・見出し・リスト・引用・コード・表・画像・ボタン・区切り線などに専用デザインあり
- エディタ上でも同じ見た目で書けるよう `assets/css/editor.css` を読み込んでいます
- カラーパレット（インク / ラベンダー / パープル など）をエディタで選べます

記事一覧（`index.php`）はカードのグリッドで、カテゴリーの絞り込みと検索フォーム付き。カテゴリー・タグ・日付アーカイブ・検索結果も同じデザインです。

**ポイント：** 抜粋を入力すると、カードと記事の見出しエリアにリード文として表示されます。アイキャッチがない記事には、ロゴ入りのプレースホルダーが表示されます。

## お知らせ投稿タイプ

管理画面の「お知らせ」から投稿できます（URLは `/news/`）。トップページには通常の投稿とお知らせを合わせた最新3件が表示されます。

ラベルを変えたい場合は、カスタムフィールド `news_type` に次のいずれかを設定してください：`maintenance` / `event` / `update` / `other`。

## ヘッダーナビ

メニュー未設定のときは「ホーム / Minecraft / ルール・参加方法 / プロダクト / ニュース / お問い合わせ」を自動表示します。

「外観 > メニュー」で `ヘッダー項目 1`〜`6` に割り当てると、それに置き換わります。

- 項目が1つのメニュー → そのままリンクとして表示
- 項目が複数のメニュー → メニュー名が親項目になり、ドロップダウンで表示（スマホではタップで開閉）

右端のボタンは「外観 > カスタマイズ > Nehaverse Header」で文言・URLを変更できます。フッターのリンクは `フッターメニュー` に割り当てると置き換わります。

## 稼働状況

「外観 > カスタマイズ > Service Status」にStatus APIのURLを入れると、トップの稼働状況が自動更新されます。未設定時は「未確認」と表示し、稼働中とは表示しません。

## モーション

| 演出 | 付け方 |
| --- | --- |
| スクロールで表示 | `data-reveal`、画像は `data-reveal="wipe"`。`style="--d:1"` で遅延 |
| 見出しの1文字ずつ表示 | `data-split` |
| 数字カウントアップ | `data-count="10" data-suffix="K+"` |
| マグネットボタン | `data-magnetic` |
| コピー | `data-copy-text="..."`（`data-copy-label` で通知文を変更） |

トップの初回ロード演出は、ブラウザのセッション中に1回だけ表示されます。OSの「視差効果を減らす」設定ではすべての動きが止まり、JavaScriptが無効でも内容は表示されます。

## 色の変更

`style.css` の先頭にある3つの変数で、全体のアクセント色が変わります。

- `--accent`：塗り（ボタン・帯）
- `--accent-strong`：線・飾り
- `--accent-deep`：小さい文字

## そのほか

- OGP画像の自動生成は v1 から引き継いでいます（`inc/ogp.php`、Imagickが必要。配色のみ新デザインに合わせて変更）
- お問い合わせのDiscord Webhook送信処理も引き継いでいます。使う場合は `wp-config.php` に `define('NEHAVERSE_DISCORD_WEBHOOK_URL', '...');` を追加してください
- 旧テンプレート用の関数 `nehaverse_page_lead()` は、新しい見出しエリアの別名として残しています
